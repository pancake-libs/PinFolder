# PinFolder（STEP1・STEP2）

> 読む順：まずこの README.md（使い方・ビルド）、次に `技術まとめ.md`（使った技術・ファイルの役割。中国語は `技术说明_zh.md`）。

## 概要

画面の右下に浮かぶ丸いボタンで常駐し、登録したフォルダ・アプリを開く道具。同じフォルダ・アプリが既に開いていれば、新しく開かずにその窓を前面に出す。

- インストール不要・管理者権限不要。`PinFolder.exe` を好きなフォルダに置いて起動する
- 設定は exe の横の `config.json`（設定画面だけが読み書きする。人は直さない）
- ログは exe の横の `to_ai_log\pinfolder_resident_YYYYMMDD_HHMISS.md`（起動 1 回 1 ファイル。12 か月で消す。異常の時はこのファイルを生成 AI に渡す）
- 社外のライブラリ・外部への通信は使わない

## 置き場所

- このフォルダは共有用の写し（2026-11-25）。使った技術とファイルの役割は `技術まとめ.md`（日本語）・`技术说明_zh.md`（中文）。`build.bat` で `bin\PinFolder.exe` ができる

| 項目 | 内容 |
|---|---|

## ビルドの手順

1. `build.bat` をダブルクリックする
2. `bin\PinFolder.exe` ができる（ログは `logs\build_YYYYMMDD_HHMMSS.log`。最後の行に終了コード）
3. 配る時は `bin\PinFolder.exe` だけを渡す（`config.json` は初めの起動で作られる）
4. PinFolder が動いている間はビルドできない（exe を上書きできない）。丸いボタンを右クリックして区画パネルを開き、右下の［終了］で終えてからビルドする

## 使い方（STEP1）

1. `PinFolder.exe` をダブルクリックする → 画面の右下（タスクバーの上）に、磁石の絵の丸いボタンが出る
2. 丸いボタンを左クリックする → 大きな PinFolder の画面が開く
3. エクスプローラーからフォルダ（または EXE）を、画面の右の枠へ引っぱって入れる → 登録される（グループが無ければ、フォルダの名前でグループができる）
4. 登録した札を押す → そのフォルダが開く（既に開いていれば、新しく開かずに前面に出る）

| したいこと | 操作 |
|---|---|
| 大きな画面を開く・閉じる | 丸いボタンを左クリック、または Ctrl+Alt+P。閉じるのは ✕ か Esc（終了はしない） |
| グループを足す | 左の［＋ グループを追加］、または左の一覧の空いた所にフォルダを入れる |
| 登録する | 右の枠・グループの行にフォルダ・EXE を入れる、または［＋ フォルダを追加］［＋ アプリを追加］ |
| 開く（開いていれば前面に出す） | 札を押す、または登録したキー |
| グループの物をまとめて開く・閉じる | ［すべて開く］［すべて閉じる］（ほかの窓は閉じない） |
| 名前を変える・消す | グループ・札を右クリック |
| キー・見た目・起動時の常駐 | 右上の［設定］、または丸いボタンを右クリック →［設定］ |
| 丸いボタンを動かす | ドラッグする（置いた場所を覚える） |
| 区画に並べる | 丸いボタンを右クリック → 区画パネル。形（2×2・2×3・2×4）を選び、右の「登録した物」から区画へ引っぱって入れ（ダブルクリックでも空いた区画へ入る）、右上の赤い［配置を適用］（開いていない物は裏で一度に開いてから、まとめて置く。開く間は画面に幕（押す前の画面の絵と真ん中の磁石）がかかり、窓が 1 つずつ出るのは見えない。並べた窓は手前に出る） |
| 並べ方を残す | 区画パネルの［保存］［別名で保存］（セット。番号が付く）。次からはセットを選んで［配置を適用］ |
| 配置パターンで切り替える | 丸いボタンの上の □（セットの番号。最大 12、横 4 つずつ。1〜4 が 1 行目、5〜8 が 2 行目）を押す（右クリックはそのセットの窓をすべて閉じる）。今のセットは赤。丸いボタン・□ にマウスを当てると小さな矢印（▲／▼）が出て、□ を出す・隠すを切り替えられる |
| 並べる先の画面 | 丸いボタンのいる画面に並べる（セカンドディスプレイに並べたい時は、丸いボタンをその画面へドラッグする） |
| 並べた一式を閉じる | 区画パネルの［配置を適用］の下の［一式を閉じる］（区画に入っている物の窓だけを閉じる。アプリは保存の確認が出る） |
| デスクトップから並べる・閉じる | `PinFolder.exe --arrange "セットの名前"`・`PinFolder.exe --close "セットの名前"` のショートカットを作って開く（PinFolder が常駐していなくてよい） |
| 手前の窓を隣の区画へ | Ctrl＋Win＋Alt＋矢印（最後に配置を適用した形で動く。端の区画より外へは出ない） |
| 終える | 区画パネルの右下の［終了］（終える前に確かめる） |
| 画面の言葉を替える | ［設定］→「全般」→「言語」で 日本語・English・中文（简体） を選んで［保存］（大きな画面と区画パネルがその言語で作り直される） |

- 知らせ（フォルダが無い・キーが使えない）は、丸いボタンの上に数秒出る

## 画面の大きさの確かめ（解像度・倍率）

- `PinFolder.exe --check-layout` を実行すると、画面は出さずに、倍率を 100〜200% に見立てて子画面と大きな画面を作り、すべてのボタンに届くか・文字が切れないかを調べる
- 結果は exe の横の `layout_check.txt`（NG の行に、どの画面のどのボタンか）とログ。終了コード 0＝すべて届く、1＝届かないボタンあり、2＝確かめが失敗
- 画面を直したら、ビルドの後に流す

## 制約事項

- `build.bat` は Shift_JIS（CP932）・CRLF で保存したまま使う（UTF-8 や LF にすると日本語のメッセージが崩れる）
- ログ（to_ai_log）には、動かした PC の利用者名・PC 名が入る。社外へ渡す時は確かめる


- エクスプローラーのタブはプログラムから切り替えられない。前面に出せるのは窓まで
- 同じ EXE が動いていれば、その窓を前面に出す（同じ EXE を 2 つは起動しない）
- exe を書き込めない場所（Program Files など）に置くと、設定とログを書けない
- 画面ごとに倍率が違う構成（ノート PC と外付けの画面など）は、画面を移した時に PinFolder が自分で大きさと文字を作り直す（exe 1 つのまま。右クリックのメニュー・説明の札・ファイルを選ぶ画面は、副の画面で大きさが合わないことがある）
- Win11 のタブで 2 つのフォルダが 1 つの窓に入っていると、2 つの区画には置けない（後の区画は空のまま。別の窓で開く）
- 管理者の権限で動いている窓は動かせない
- 幕は並べる先の画面だけにかかる。エクスプローラーが別の画面に窓を出す時や、いつも手前に出るアプリの窓は、隠すまでの一瞬が見えることがある。幕は最長 8 秒で自分で外れる
- 画面の言葉を替えても、ログ（to_ai_log）は日本語のまま（生成 AI に渡すため）。登録した名前・セットの名前など、利用者が付けた名前は訳さない
- STEP3（VS Code・Claude Code の起動）はまだ無い
